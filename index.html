راهنمای سریع

۱) در تب تنظیمات Endpoint، مدل و کلید را وارد کنید. ۲) PDFهای جلسه، رزومه، پروپوزال و سایر اسناد را اضافه کنید. ۳) درخواست دقیق خود را بنویسید. ۴) برنامه تحلیل را اجرا کنید. برنامه ابتدا متن PDFها را در مرورگر استخراج و به قطعات محدود تقسیم می‌کند، سپس هر قطعه را جداگانه برای تحلیل زمینه‌ای می‌فرستد و در مرحله نهایی خلاصه‌های ساختاریافته را برای تولید پاسخ نهایی به مدل می‌دهد.

نکته امنیتی: چون این HTML مستقیماً از مرورگر به API متصل می‌شود، سرویس API باید CORS مناسب برای Origin شما داشته باشد. اگر خطای CORS/NetworkError گرفتید، نسخه Local Proxy پایتون راه‌حل مطمئن‌تری است.

نکته کیفیت: PDFهای اسکن‌شده که متن قابل انتخاب ندارند، نیازمند OCR هستند. این نسخه متن PDF را استخراج می‌کند؛ OCR را می‌توان در نسخه بعدی اضافه کرد.
